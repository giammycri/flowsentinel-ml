# FlowSentinel-ML

A machine learning pipeline for **network intrusion detection** on the [CICIDS2017](https://www.unb.ca/cic/datasets/ids-2017.html) dataset (Wednesday working-hours capture). It trains and evaluates three classifiers — **Random Forest**, **XGBoost**, and **Decision Tree** — on both a **binary** task (BENIGN vs. ATTACK) and a **multiclass** task (specific attack type), across 5 random seeds, with automated hyperparameter tuning, statistical significance testing, and result plots.

## Overview

The pipeline is split into three sequential stages, each a standalone script:

1. **Preprocess** the raw CSV into clean, cached NumPy arrays.
2. **Tune** hyperparameters for every (task × seed × model) combination via `RandomizedSearchCV`, saving each fitted model to disk.
3. **Evaluate** every saved model on its held-out test set, aggregate metrics across seeds, run Wilcoxon signed-rank tests, and generate confusion-matrix / feature-importance plots.

Each stage caches its output, so re-running the pipeline after an interruption (crash, killed process, etc.) skips work that's already done instead of starting over.

## Repository structure

```
.
├── config.py                  # Single source of truth for all parameters (paths, seeds, model settings)
├── 01_preprocess.py            # Stage 1: clean the raw CSV, save arrays to data_cache/
├── 02_tune.py                   # Stage 2: hyperparameter search + fit, save models to models/
├── 03_evaluate.py                # Stage 3: score models, save metrics/plots to output/
├── ml_pipeline.py                # Legacy: original single-file, all-in-one version of the pipeline (no caching/resume — kept for reference)
├── run_all.sh                     # Runs 01 → 02 → 03 in sequence, in the foreground
├── launch.sh                      # Runs run_all.sh detached (nohup + setsid) so it survives closing the terminal/VSCode
├── perstopparetutto.txt           # Notes: shell commands to stop the background pipeline and its child processes
├── data_cache/                    # Preprocessed arrays (generated by 01_preprocess.py)
├── models/                         # Fitted model files (generated by 02_tune.py)
├── output/                          # Metrics tables and plots (generated by 03_evaluate.py)
└── logs/                             # Timestamped run logs + PID file (used by launch.sh)
```

### `config.py`

Central configuration dictionary (`CONFIG`) imported by every script. Defines the dataset path, the 5 experiment seeds, the train/test split ratio, the number of `RandomizedSearchCV` candidates per model, the correlation threshold used to drop redundant features, and the directory names for cache/models/output/logs. Creates those directories on import if they don't already exist. Edit this file to change any pipeline parameter — nothing is hardcoded elsewhere.

### `01_preprocess.py`

Loads the raw CICIDS2017 CSV and turns it into model-ready arrays:

- Strips whitespace from column names and drops duplicate columns.
- Replaces `inf`/`-inf` with `NaN` and drops affected rows.
- Drops duplicate rows and zero-variance (constant) columns.
- Casts features to `float32` to halve memory usage.
- Runs a **Pearson correlation filter**: for any pair of features with `|r| > 0.95`, drops one of the two.
- Encodes labels two ways: **binary** (`BENIGN` vs. `ATTACK`) and **multiclass** (`LabelEncoder` over the original attack-type strings).
- Saves everything to `data_cache/` as `.npy`/`.json` files.

Skips re-processing entirely if a valid cache already exists (delete `data_cache/` to force a rebuild). Requires the source CSV file (see [Dataset](#dataset) below).

### `02_tune.py`

For every combination of task (`binary`, `multiclass`) × seed (`42, 43, 44, 45, 46`) × model (`RandomForest`, `XGBoost`, `DecisionTree`):

- Reconstructs the same stratified 70/30 train/test split (per seed).
- Runs `RandomizedSearchCV` (20 candidates, 3-fold CV, `f1_weighted` scoring) over a model-specific hyperparameter grid.
- Refits the best estimator on the full training set and saves it to `models/<task>_seed<seed>_<model>.pkl`.
- Records the best CV score, best parameters, and tuning time in `models/best_params.json`.

**Resumable by design**: before tuning a given combination it checks whether the corresponding `.pkl` already exists and skips it if so — so re-running after a crash picks up exactly where it left off. XGBoost is configured to use `device="cuda"` (GPU) if available.

### `03_evaluate.py`

Loads every fitted model from `models/`, reconstructs the identical test split used during tuning (same seed), and computes:

- **Accuracy, precision, recall, F1 (weighted), ROC-AUC, inference time** per (task, seed, model).
- **Mean ± std across the 5 seeds**, saved as a summary table.
- **Wilcoxon signed-rank tests** comparing each pair of models (RF vs. XGBoost, RF vs. DecisionTree, XGBoost vs. DecisionTree) per task, to check whether performance differences are statistically significant (α = 0.05).
- **Confusion matrix** plots for every model/task (from the last seed).
- **Feature importance** plots (top 20) for RandomForest and XGBoost (from the last seed).

All results are written to `output/`.

### `ml_pipeline.py`

The original, monolithic version of the pipeline: preprocessing, tuning, and evaluation all in one script with no caching or resume support. It has been superseded by the `01_preprocess.py` → `02_tune.py` → `03_evaluate.py` split (which adds caching, resumability, and independently re-runnable stages), but is kept in the repo for reference.

### `run_all.sh` / `launch.sh`

- `run_all.sh` runs the three stages back-to-back in the foreground and stops immediately if any stage fails (`set -e`).
- `launch.sh` starts `run_all.sh` in the background via `nohup` + `setsid`, writing a timestamped log to `logs/` and the process's PID to `logs/pipeline.pid`, so the full run (which can take hours due to hyperparameter search) survives closing the terminal or VSCode. Pass `--follow` to also tail the log live. Use `perstopparetutto.txt` for the commands to stop it.

## Data folders

| Folder | Contents | Generated by |
|---|---|---|
| `data_cache/` | `X.npy` (feature matrix), `y_binary.npy` / `y_multiclass.npy` (labels), `feature_names.json`, `class_labels_binary.json`, `class_labels_multiclass.json` | `01_preprocess.py` |
| `models/` | One `.pkl` per (task, seed, model) combination — 30 files total (2 tasks × 5 seeds × 3 models) — plus `best_params.json` | `02_tune.py` |
| `output/` | `all_results_raw.csv` (per-seed metrics), `results_summary.csv` (mean ± std), confusion-matrix and feature-importance PNGs | `03_evaluate.py` |
| `logs/` | Timestamped pipeline logs and the background-run PID file | `launch.sh` |

## Dataset

This repository does **not** include the raw dataset — `Wednesday-workingHours.pcap_ISCX.csv` (~225 MB) exceeds GitHub's file size limits and is excluded via `.gitignore`. Download it from the official [CICIDS2017 dataset page](https://www.unb.ca/cic/datasets/ids-2017.html) and place it in the repository root before running `01_preprocess.py` (or update `csv_path` in `config.py` to point elsewhere).

## Usage

```bash
# Full pipeline, foreground
bash run_all.sh

# Or, run in background (survives closing the terminal)
bash launch.sh --follow

# Or, run each stage independently
python3 -u 01_preprocess.py
python3 -u 02_tune.py
python3 -u 03_evaluate.py
```
